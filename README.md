# Аллокатор доходов

Telegram-бот для управления личными финансами.

## Структура проекта

- `bot.py` — точка запуска и сборка роутеров.
- `financial_engine.py` — финансовые расчёты и распределение дохода.
- `storage.py` — хранение профилей, операций и обязательств в SQLite.
- `onboarding.py` — первоначальная настройка пользователя.
- `settings_editor.py` — изменение настроек после онбординга.
- `income.py`, `period.py`, `taxes.py`, `planned_payments.py` — основные финансовые сценарии.
- `dashboard.py`, `forecast.py`, `charts.py` — отчёты и прогнозы.
- `goals_manager.py`, `brackets.py`, `debts.py` — отдельные финансовые механики.
- `assets/` — изображения и шрифты интерфейса.
- `docs/` — документация и примеры.
- `scripts/` — служебные скрипты.
- `tests/` — автоматические тесты.

## Проверка

```bash
python3 -m unittest discover -s tests
```

Локальные секреты и пользовательские данные (`.env`, `allocator.db*`,
`backups/`) исключены через `.gitignore` и не должны передаваться вместе с
исходным кодом.
