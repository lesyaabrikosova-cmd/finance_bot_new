# Актуальные превью

Здесь хранятся только актуальные примеры интерфейса для документации и
визуальной проверки. Бот не читает эти файлы во время работы: изображения для
Telegram создаются соответствующими рендерами в памяти.

| Файл | Экран | Источник |
|---|---|---|
| `brackets-piecework-5.png` | Карточка настроек Бракетов для сдельного профиля | `bracket_card.py` |
| `goals-and-chests-card.png` | Главный экран «Цели и Сундуки» | `goals_card.py` |
| `reserves-stable.png` | Защитные резервы стабильного профиля | `reserve_card.py` |
| `reserves-piecework.png` | Подушка и Стабилизатор сдельного профиля | `reserve_card.py` |
| `reserves-cyclic.png` | Фонд зарплаты и Подушка циклического профиля | `reserve_card.py` |
| `income-analysis-chart.png` | Источники дохода за текущий расчётный период | `charts.py`, данные формирует `dashboard.py` |
| `goals-allocation-chart.png` | Доли распределения между активными Целями и Сундуками | `charts.py` |
| `period-balances-chart.png` | Пополнения конвертов за расчётный период | `charts.py`, данные формирует `dashboard.py` |
| `taxes-chart.png` | Налоговая статистика по типам и правилам | `charts.py`, данные формирует `taxes.py` |

Все суммы и названия в превью условные и не содержат пользовательских данных.
Полный набор можно воспроизвести командой:

```bash
python3 scripts/generate_doc_previews.py
```

При заметном изменении одного из этих экранов превью следует заменить новым
изображением с тем же назначением. Устаревшие примеры перемещаются в
`docs/archive/previews-legacy/`, чтобы их не путали с текущим интерфейсом.
