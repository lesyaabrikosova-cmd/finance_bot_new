# PT Sans

Кириллический шрифт для программно создаваемых карточек. Файлы включены в
проект, чтобы отрисовка не зависела от шрифтов на сервере или сети.

Источник: https://github.com/google/fonts/tree/main/ofl/ptsans

- PT_Sans-Web-Regular.ttf → PTSans-Regular.ttf
- PT_Sans-Web-Bold.ttf → PTSans-Bold.ttf

Лицензия: SIL Open Font License 1.1, см. OFL-PTSans.txt. Шрифты не изменены.
